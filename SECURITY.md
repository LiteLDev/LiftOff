# Security Policy

## Supported versions

Only the latest release of LiftOff receives fixes.

## Reporting a vulnerability

Please do **not** open a public issue for security problems, such as a way for players without operator permission to run admin commands, duplicate items or change other players' data. Report them privately through [GitHub's private vulnerability reporting](https://github.com/LiteLDev/LiftOff/security/advisories/new) instead. You should get a response within a week. Once a fix is released, the issue is disclosed.
